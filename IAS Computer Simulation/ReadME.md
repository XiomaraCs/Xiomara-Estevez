Simulation of Von Neumann Computer Architecture (IAS). 

Simulates instruction fetch, execute and decode cyces using the opcodes and stored data programming concept. Outputs the results to an output.txt file created in main drive test cpp. 

To run:
run main.cpp file
The seperate instruction cycles and necessary functions are all seperated in header files to simulate different parts and register usage in the cpu and memory.

Which are then combined to work together in the main drive file.
